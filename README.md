# Ford Car Price Prediction

## Project Overview

This project focuses on analyzing Ford car data and predicting car prices using Python and machine learning techniques.

The project includes data loading, data understanding, exploratory data analysis (EDA), data cleaning, data preprocessing, visualization, and machine learning.

## Dataset

The dataset used in this project is the **Ford Car Price Prediction** dataset.

The dataset is downloaded using KaggleHub from Kaggle.

## Project Workflow

```text

   ↓

   ↓

```
